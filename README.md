## 🗂️ Lab format

Each lab folder contains:

- **README.md:** goal, setup, steps and what I learned
- **configs/:** policies or IaC used (no secrets, ever)
- **screenshots/:** evidence of the result

> 🔐 All labs run on free tier accounts. No credentials or keys are ever committed.
